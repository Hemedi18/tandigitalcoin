{% trans "How money moves" %}

{% blocktrans trimmed %}Your balance is the sum of unspent outputs that pay your address. A payment spends those outputs and creates new outputs for the receiver and usually change back to you. The miner fee is the difference between input total and output total.{% endblocktrans %}

inputs → transaction → outputs (receiver + change)
                              ↘ fee to miner

{% trans "Making a payment" %}

{% trans "Signing is implemented in Python today. Typical steps:" %}

  1. {% trans "Confirm the sender has UTXOs on chain." %}
  2. {% trans "Pick inputs that cover amount plus fee." %}
  3. {% trans "Call Chain.create_transfer then POST /api/chain/tx/submit/." %}
  4. {% trans "Run POST /api/chain/mine/ or wait for a miner." %}

{% trans "Django shell example" %}

import os, django
os.environ.setdefault("DJANGO_SETTINGS_MODULE", "tancoin.settings")
django.setup()

from chain_api.services import node
from tancoin_core.wallet import Wallet

chain = node.get_chain()
alice = Wallet.from_wif("ALICE_WIF")
bob = Wallet.generate()

utxos = chain.get_utxos_for_address(alice.address())
u = max(utxos, key=lambda x: x["value"])
txid = bytes.fromhex(u["txid"])
idx = int(u["index"])

amount = 1_000_000
fee = 50_000
prev_val = chain.utxo[(txid, idx)].value
change = prev_val - amount - fee
if change < 0:
    raise SystemExit("not enough funds")

tx = chain.create_transfer(alice, bob.address(), amount, [(txid, idx)], change)
node.submit_transaction(tx.to_dict())
node.mine_block()

{% blocktrans trimmed %}After mining, Bob sees a new output. Alice receives change as a new output.{% endblocktrans %}

{% trans "Mining" %}

{% blocktrans trimmed %}Mining does not run in the background here. Whoever POSTs to /api/chain/mine/ builds the block, does proof of work, and clears the mempool.{% endblocktrans %}

curl -s -X POST http://127.0.0.1:8000/api/chain/mine/ \
  -H "Content-Type: application/json" \
  -d '{"miner_wif":"MINER_WIF"}'

{% blocktrans trimmed %}You may omit the body in local demos so fees go to the genesis wallet. Lock this down in production.{% endblocktrans %}
