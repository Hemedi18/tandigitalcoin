{% trans "Protecting secrets" %}

  • {% trans "Never store WIF in git, screenshots, or chat." %}
  • {% trans "Use environment variables or a secrets manager in production." %}
  • {% trans "If a key leaks, move funds to a new address with a new key." %}

{% trans "Genesis wallet" %}

{% blocktrans trimmed %}On first start the node writes data/genesis_wallet.json. The /api/dev/genesis-wallet/ route only works when DEBUG is True. Turn DEBUG off in production and block that route.{% endblocktrans %}

{% blocktrans trimmed %}The genesis wallet receives the first large reward. Treat it as a mint key with very high privilege.{% endblocktrans %}

{% trans "CSRF and browser clients" %}

{% blocktrans trimmed %}Some JSON POST routes skip CSRF so command-line tools work. Browser apps that talk to the same routes should use CSRF tokens or send writes through your own backend.{% endblocktrans %}

{% trans "Network" %}

{% blocktrans trimmed %}Use HTTPS in production, set ALLOWED_HOSTS correctly, and put the node behind a proxy with rate limits. This build has no peer-to-peer layer.{% endblocktrans %}

{% trans "Checklist" %}

  1. {% trans "DEBUG off, strong SECRET_KEY, real database if you add accounts." %}
  2. {% trans "Encrypt backups of TANCOIN_DATA_DIR." %}
  3. {% trans "Watch /api/chain/mine/ for abuse." %}
  4. {% trans "Scale reads separately if the explorer grows." %}
