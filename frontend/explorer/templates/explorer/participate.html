{% trans "Roles in one sentence" %}

  • {% blocktrans trimmed %}User: holds keys, builds a signed transaction that spends UTXOs and pays a receiver plus a fee to miners.{% endblocktrans %}
  • {% blocktrans trimmed %}Miner: collects mempool transactions, builds a block, finds proof of work, publishes the block, and collects the coinbase reward and fees.{% endblocktrans %}
  • {% blocktrans trimmed %}Everyone: can read the public explorer at the home, transactions, and address pages.{% endblocktrans %}

{% trans "Create or load a wallet" %}

{% blocktrans trimmed %}A wallet is a private key stored as WIF and a Base58 address you share to receive funds.{% endblocktrans %}

curl -s http://127.0.0.1:8000/api/wallet/new/

{% blocktrans trimmed %}Store address and WIF in a password manager. Anyone with the WIF can spend your coins.{% endblocktrans %}

{% trans "Act as a miner" %}

{% blocktrans trimmed %}Mining builds the next block from the mempool and runs proof of work. Fees go to the miner_wif you send, or to the genesis wallet if you omit the body.{% endblocktrans %}

  -H "Content-Type: application/json" \
  -d '{"miner_wif":"YOUR_WIF_HERE"}'
